## About

Computer Science student at **Strathmore University, Nairobi** (Class of 2027). I build software for real local needs (agriculture, services, housing, onboarding), and I'm growing my range across full-stack, AI/ML and DevOps so that what I build can reach and serve more people. I want to own the full path: build, deploy, secure, maintain.
