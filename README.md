# Hi, I'm Nicole Mumo

I'm a Computer Science student at **Strathmore University (Class of 2027)**, based in Nairobi, Kenya.

I mostly build Android apps in Kotlin, and I'm also working on machine learning and full-stack web projects. Most of what's below is built around problems I see locally: farming, services, property, and sales.

---

# Current Focus

**AI and Machine Learning**
- Machine learning and predictive models
- How computers learn patterns from data
- Deep learning and neural networks
- Building and evaluating practical AI systems

**Full-Stack Development**
- React and Next.js on the frontend, Node.js on the backend
- APIs, databases, and complete web applications
- Developing further: TypeScript, JavaScript, PostgreSQL

**Android Development**  
- Kotlin, Jetpack Compose, and Firebase

# Featured Projects

## AI and Machine Learning

### [Sales Onboarding Guidance System (AI)](https://github.com/NicoleMumo/SALES-ONBOARDING-GUIDANCE-SYSTEM-AI-)

An Android AI assistant that uses a Transformer model to guide sales agents through customer onboarding, validate the information they collect, and predict the next step.

**Tech:** Python • Transformers • Pandas • Scikit-learn  
**Status:** In development

---

## Full-Stack and Web

### [Farm Direct E-Commerce Website](https://github.com/NicoleMumo/FARM-DIRECT-ECOMMERCE-WEBSITE)

Full-stack e-commerce platform with online payment support.

**Tech:** React • Node.js • PHP • MySQL • Pesapal

### [Kazi Road Service Marketplace](https://github.com/NicoleMumo/KAZI-ROAD-SERVICE-MARKETPLACE)

Frontend prototype of a marketplace connecting customers with local service providers, with separate customer and admin views. It currently uses mock data; authentication and a backend are not built yet.

**Tech:** Next.js • React • TypeScript • Tailwind CSS • Three.js

### [Real Estate Management System](https://github.com/NicoleMumo/Real-Estate-Management-System)

Property management platform with M-Pesa STK Push payments. Forked from [ianwambaire/Real-Estate-Management-System](https://github.com/ianwambaire/Real-Estate-Management-System).

**Tech:** PHP • MySQL • M-Pesa API

### [Mini Cinema](https://github.com/IS-PROJECT-2026/mini-cinema-169979)

Web app for watching YouTube videos together. Users create or join rooms with a code, the host's playback syncs to everyone, and each room has live chat and emoji reactions. [Live demo](https://is-project-2026.github.io/mini-cinema-169979/).

**Tech:** JavaScript • Firebase Realtime Database • YouTube IFrame Player API • GitHub Pages

---

## Android

### [Farm Direct Mobile App](https://github.com/NicoleMumo/FARM-DIRECT-MOBILE-APP)

Android prototype of a farm-to-consumer marketplace with farmer, consumer, and admin roles. Farmers manage products and orders, consumers browse and order, and admins monitor users and listings.

**Tech:** Kotlin • Jetpack Compose • Firebase Auth • Firestore

---

## IoT

### [Agriculture IoT Project](https://github.com/NicoleMumo/AGRICULTURE-IOT-PROJECT)

Low-cost smart farming system that monitors soil moisture, temperature, and humidity, and shows live data, trends, and crop-specific irrigation recommendations on a web dashboard.

**Tech:** ESP32 • MQTT • PHP • MySQL
