# Projects

### [Sales Onboarding Guidance System (AI)](https://github.com/NicoleMumo/SALES-ONBOARDING-GUIDANCE-SYSTEM-AI-)
An Android AI assistant that uses a Transformer model to guide sales agents through customer onboarding, validate the information they enter, and predict the next step.
`Android` `Python` `Transformers` `Scikit-learn`

### [Agriculture IoT Project](https://github.com/NicoleMumo/AGRICULTURE-IOT-PROJECT)
A low-cost smart farming system that monitors soil moisture, temperature, and humidity to help smallholder farmers decide when to water. A web dashboard shows live readings, historical trends, and crop-specific irrigation recommendations.
`ESP32` `MQTT` `PHP` `MySQL`

### [Farm Direct Mobile App](https://github.com/NicoleMumo/FARM-DIRECT-MOBILE-APP)
An Android prototype of a farm-to-consumer marketplace with three roles. Farmers manage products and orders, consumers browse and place orders, and admins monitor users and listings.
`Kotlin` `Jetpack Compose` `Firebase Auth` `Firestore`

### [Farm Direct E-Commerce Website](https://github.com/NicoleMumo/FARM-DIRECT-ECOMMERCE-WEBSITE)
The web storefront for Farm Direct, with Pesapal payments.
`React` `Node.js` `PHP` `MySQL`

### [Kazi Road Service Marketplace](https://github.com/NicoleMumo/KAZI-ROAD-SERVICE-MARKETPLACE)
A frontend prototype of a marketplace that connects customers with local service providers. It has service browsing, booking-style screens, and separate client and admin views. It uses demo data for now, so authentication and a backend are still to be added.
`Next.js` `React` `TypeScript` `Tailwind CSS` `Three.js`

### [Mini Cinema](https://github.com/IS-PROJECT-2026/mini-cinema-169979)
A watch-party web app. Friends join a room with a code and watch a YouTube video in sync, with live chat and emoji reactions. **[Try the live demo](https://is-project-2026.github.io/mini-cinema-169979/)**
`JavaScript` `Firebase Realtime Database` `YouTube IFrame API`

### [Real Estate Management System](https://github.com/NicoleMumo/Real-Estate-Management-System)
A property management web app with bookings, a support helpline, and M-Pesa payment integration. This is my fork of [ianwambaire's project](https://github.com/ianwambaire/Real-Estate-Management-System).
`PHP` `MySQL` `M-Pesa`
