About Me

I’m a Computer Science student at Strathmore University in Nairobi, Kenya (Class of 2027).

I’ve built software for real-world needs around me, including agriculture, local services, housing, and customer onboarding. I’m now focusing on building complete software products, understanding how they run in the cloud, and developing intelligent systems with AI and machine learning.

My main focus is Full-Stack Development and Cloud Engineering, alongside AI/ML Engineering. I also want to understand security as part of building reliable software: securing applications, cloud infrastructure, and AI-powered systems.

What I’m Focusing On

Area	What I’m Learning
Full-Stack Development	Building frontend interfaces, backend APIs, databases, authentication, and complete web applications using React, Next.js, Node.js, TypeScript, and SQL.
Cloud Engineering	Learning deployment, Linux, networking, cloud infrastructure, containers, CI/CD, automation, monitoring, and system reliability.
AI/ML Engineering	Working with Python, data processing, machine learning, neural networks, model training, evaluation, and deployment.
Security Across My Projects	Applying secure authentication, authorization, input validation, API protection, cloud access controls, secrets management, and AI/ML security practices.

I want to understand not just how to write code, but how to build, deploy, secure, and maintain systems that solve meaningful problems.

Security Is Part of What I Build

I’m interested in cybersecurity not only as a field to explore, but as an essential part of developing software and AI systems.

Security Area	What I Want to Practise
Application Security	Secure authentication and authorisation, input validation, API security, dependency management, and protection against common web vulnerabilities.
Cloud Security	Identity and access management, least privilege, secure configurations, secrets management, encryption, logging, and monitoring.
AI/ML Security	Protecting sensitive data, validating model inputs, controlling access to models, and understanding threats such as data poisoning and prompt injection.

My goal is to make security part of the development process from the beginning, rather than treating it as something to add at the end.
